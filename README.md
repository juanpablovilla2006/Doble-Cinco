Pasos para correr el código correctamente:

1. Tener Node.js (el proyecto usa: v24.14.1) y MySQL instalados
2. Ejecutar npm install en la carpeta \backend. Ejecutra npm install en la carpeta \frontend
3. Crear una database en mySQL workbench llamada "doble_cinco". Luego desde la terminal en \backend correr: "npx drizzle-kit push"
4. Abrir dos terminales, una en backend y otra en frontend. Ejecutar en cada una: npm run dev
